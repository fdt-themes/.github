# FDT – Fixed Discord Themes

Abandoned Discord themes, adopted and kept working on the current Discord UI. Part of [FDT](https://kazrutx.github.io/discord-themes-fixed/), run by the FDT team.

Founder: [@KAZRUTx](https://github.com/KAZRUTx)

## Adoption rules
- Open license only (MIT, GPL, CC BY…).
- Only themes that are archived or have had no activity or replies for a long time.
- Original license and credits always stay. The original author is always named first.
- If the author comes back, we hand it back. Just ask.
